# oh-my-library

我用 vibe coding 写的小程序合集。每个程序都自包含，可以单独拷出来安装和运行，用法见各程序目录里的 README。

| 分类 | 程序 | 说明 |
|---|---|---|
| 工具 | [Voice-to-Text](Tools/Voice-to-Text/) | 按住说话，识别后自动粘贴到终端窗口（Ubuntu / X11） |
| 工具 | [Memo](Tools/Memo/) | 桌面待办和 Markdown 笔记，常驻系统托盘（Linux / Windows） |
| 博客 | [bangumi-list](Blog/bangumi-list/) | WordPress 插件：终端风格的看番清单页面 |
| 博客 | [week-plan](Blog/week-plan/) | WordPress 插件：后台周计划表，把待办按天排期 |
| 博客 | [ai-pet](Blog/ai-pet/) | WordPress 插件：会聊天、会推荐站内文章的看板角色 |
| VPS | [IP-check2ippure](VPS/IP-check2ippure/) | 批量检测机场订阅各节点的出口 IP 质量 |

许可证见各程序目录下的 `LICENSE`。
